## Tier 0 — live security bug (fix now)

- [ ] **SSRF/metadata bypass via IPv4-mapped / NAT64 IPv6 literals** (`net.rs:54-71`, CONFIRMED high).
  `ip_kind()` V6 branch never unwraps an embedded v4, so `::ffff:169.254.169.254`,
  `::ffff:127.0.0.1`, `::ffff:10.0.0.1`, `64:ff9b::a9fe:a9fe` all classify as `Public`.
  Primary AI transport runs `allowPrivateNetwork:true` (`agent.ts:31`), so the unconditional
  metadata block is the only residual defense — and it is defeated. URL
  `http://[::ffff:169.254.169.254]/latest/meta-data/` reaches cloud IMDS, body streamed to model.
  Fix: at top of V6 branch, `if let Some(v4)=v.to_ipv4_mapped() { return ip_kind(IpAddr::V4(v4)); }`
  (+ handle NAT64 `64:ff9b::/96`). Add tests mirroring `metadata_ips_classified_as_blocked`.
- [ ] **Trailing-dot FQDN slips the metadata name check** (`net.rs:24-30`, low). `metadata.google.internal.`
  passes `is_blocked_host_name`. Fix: `host.trim_end_matches('.')` before compare. One line.

## Tier 1 — security defense-in-depth

- [ ] **Auto-exec grep/glob returns secret-file contents** (`search.ts:70,110` + `grep.rs:159-164`, medium).
  Deny-list only checks the root dir, not matched files. Non-dot/non-ignored secrets (`*.tfstate`,
  `firebase-adminsdk-*.json`, `*.ppk`, `rclone.conf`) get content-searched and returned to the model
  with no approval. Fix: run `SECRET_BASENAME_PATTERNS` per hit/basename before returning.
- [ ] **Extend SECRET_BASENAME_PATTERNS** (`security.ts:31-98`, low/trivial). Add `*.ppk`, `*.tfstate`,
  `.vault-token`, `rclone.conf`, shell `*_history`, browser cred stores; PROTECTED_DIRS for rclone/vault.
- [ ] **fs_* IPC commands enforce no workspace authz** (`fs/file.rs:49-205`, medium). Unlike `shell_*`/watch
  (which call `registry.is_authorized`), raw fs read/write rely solely on the JS deny-list. Decide:
  route through the registry, or record explicitly that security.ts is the sole AI gate.
- [ ] **Forged OSC 777 agent marker** (`agent_detect.rs:162-215`, low). Detector trusts raw PTY bytes and
  self-arms; a remote SSH host / `cat`'d file can print `notify;Termul;finished` to trigger a managed
  AI review round. Fix: only honor 777 when armed by a real OSC 133 C agent command.

## Tier 2 — performance / bundle (lightweight bar)

- [ ] **CodeMirror manualChunks monolith** (`vite.config.ts:76-81`, medium, HIGH VALUE). All 12 langs + 8

  tab opens — defeating the per-language `import()` loaders already written. Fix: drop the catch-all (or
  scope to core only) so rollup honors the import boundaries; make `themes.ts` load only the active theme.
- [ ] **vim statically imported** (`EditorPane.tsx:19`, low). Ships for every editor user though opt-in.

- [ ] **dropHibernatedOutput off = unbounded RAM ring** (`useTerminalSession.ts:352-356,416-428`, medium).
  Noisy hidden tab (`yes`, chatty build) grows webview RAM without bound + keeps IPC hot. Fix: hard-cap
  the dormant ring even in keep-all mode and steer truly-unbounded to disk spill.

  listeners re-run on every `tabs` change (every `cd`), rebuilding ~10 closures + writing chatStore.
